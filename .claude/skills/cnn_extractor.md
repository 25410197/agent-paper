# SKILL: DEEP LEARNING PAPER EXTRACTION
Khi đọc một file PDF, bạn phải dùng kỹ năng này để tìm kiếm và trích xuất:
- Framework: PyTorch, TensorFlow, Keras hay Caffe?
- Input size: Kích thước ảnh (ví dụ: 3x224x224 cho PyTorch hoặc 224x224x3 cho TF).
- Data Augmentation: Tên các phép biến đổi dữ liệu tác giả đã dùng.
- CNN Architecture: Số lượng Layer, Filter, Kernel, MaxPooling, Activation, Batch Normalization, Dropout.
- Optimization: Hàm Loss (CrossEntropyLoss), Optimizer (Adam/SGD), Learning Rate, Batch Size, Epochs.
