## Abstract

Plant-disease diagnosis aimed at resource-constrained devices needs a model that is both accurate and lightweight. This work proposes ChiliEdgeNet, a CNN-Transformer hybrid architecture built by truncating MobileNetV2 and integrating a Tiny Transformer block. We also introduce ChiliEdge-DS, a publicly released dataset of 2,461 chili pepper leaf and fruit images across five classes. ChiliEdgeNet reaches 98.93% accuracy with 671,173 parameters, about 35% fewer than the base architecture. The model is 2.7 MB and has an inference latency of 20.24 ms/image on a server-class CPU. In a synthetic brightness-reduction stress test at factor 0.2, the full model outperforms the variant without the Transformer by 3.75 percentage points. On a clean cross-dataset query set of 1,463 images across four classes shared with Mendeley Data, accuracy rises from 30.96% at the original checkpoint to 89.75% after adapting with 42 support images; both checkpoints use seed 42. These results position ChiliEdgeNet as a candidate for offline inference on resource-constrained hardware, but direct evaluation on edge hardware and domain-transfer confirmation on more independent datasets remain necessary.
